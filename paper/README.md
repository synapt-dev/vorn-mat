# Paper Source

LaTeX source for *Vorn: Residual Direction, Familial Eviction, and the Granularity Rescue Spectrum* (v1.1, June 2026).

This directory is the canonical source for the paper PDF that ships at [synapt.dev/vorn-mat/](https://synapt.dev/vorn-mat/) and the Zenodo deposit.

## Build

```bash
pdflatex vorn-mat-premiere.tex
bibtex vorn-mat-premiere
pdflatex vorn-mat-premiere.tex
pdflatex vorn-mat-premiere.tex
```

Output: `vorn-mat-premiere.pdf` (~42 pages, ~670 KB).

## TMLR Submission Build

The TMLR review submission source is `vorn-mat-tmlr.tex`. It is an
anonymized derivative of `vorn-mat-premiere.tex` for double-blind TMLR
review. The public Zenodo source remains `vorn-mat-premiere.tex`.

```bash
pdflatex vorn-mat-tmlr.tex
bibtex vorn-mat-tmlr
pdflatex vorn-mat-tmlr.tex
pdflatex vorn-mat-tmlr.tex
```

Output: `vorn-mat-tmlr.pdf` (~41 pages, ignored as a build artifact).

The vendored TMLR style files are `tmlr.sty` and `tmlr.bst`; upstream
provenance is recorded in `TMLR_STYLE_UPSTREAM.txt`.

## Files

- `vorn-mat-premiere.tex` — main source
- `vorn-mat-tmlr.tex` — anonymized TMLR submission source
- `refs.bib` — bibliography
- `tmlr.sty`, `tmlr.bst` — TMLR submission style files
- `figures/` — figure assets (PDFs generated by `figures/generate_figures.py`)
